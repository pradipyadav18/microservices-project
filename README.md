# Microservices Project

A hands-on Microservices project built using **Java and Spring Boot** to understand how real-world backend services are designed and connected.

## 🚀 Employee Service

The first service in this project is the **Employee Service**.

### Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* MySQL
* REST APIs
* Maven

### Features

* Create Employee
* Get Employee
* Get All Employees
* Update Employee
* Delete Employee
* Exception Handling
* DTO & Entity Mapping
* MySQL Database Integration

## 🔄 Upcoming Services

More services will be added as the project progresses.

Planned technologies:

* Eureka Service Discovery
* OpenFeign
* Service-to-Service Communication
* Spring Cloud

## 🎯 Goal

The goal of this project is to learn and implement **Microservices architecture** by building and connecting multiple independent services step by step.
